A modern and responsive electronics store built using React and Vite.
The application provides users with an easy way to browse electronic products, search for items, filter by categories, and sort products based on different criteria.

** Features:
1.Browse electronic products.
2.Filter products by category.
3.Search for products by name.
4.Sort products by price (Low to High / High to Low).
5.Sort products by rating.
6.Responsive design for different screen sizes.
7.Clean and user-friendly interface.

** Technologies Used:
React.js
JavaScript
HTML5
Tailwind CSS
